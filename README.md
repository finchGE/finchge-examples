# FinchGE example projects

This repository contains example projects demonstrating FinchGE API usage. Each example is self-contained, with its own grammar, config, and `main.py`.

## Examples

| Example | Description |
|---|---|
| [`stringmatch`](stringmatch) | Classic string-match problem using genome-based representation (one-point crossover, integer-flip mutation). |
| [`stringmatch_tree_based`](stringmatch_tree_based) | Same string-match problem using tree-based representation (subtree crossover/mutation, PI-Grow initialisation). |
| [`symbolic_regression/ngyuen6`](symbolic_regression/ngyuen6) | Symbolic regression on the Nguyen-6 benchmark, with parallel (process-based) fitness evaluation. |
| [`symbolic_regression/keijzer7`](symbolic_regression/keijzer7) | Symbolic regression on the Keijzer-7 benchmark (single-variable log function). |

This list is kept up to date as new examples are added.
